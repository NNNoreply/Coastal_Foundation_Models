# Coastal Foundation Models

Research on transferable Earth observation representations for coastal environments.

This repository accompanies the manuscript **Towards Coastal Foundation Models: Task Trade-offs and Frozen Feature Complementarity**. The study explores coastal adaptation, mixture-of-experts models, and frozen feature fusion for shoreline segmentation, marine surface segmentation, and bathymetry estimation.

The repository currently contains this project overview. Code, model checkpoints, and data are not included in this initial release.
