# Coastal Foundation Models

Research on coastal representation learning with optical and depth foundation models.

This repository accompanies the working manuscript **Coastal Representation Learning by Combining Optical and Depth Foundation Models**. The central method combines frozen OLMoEarth optical features with frozen PromptDA depth-model features through spatial alignment and feature concatenation, followed by task-specific linear probing.

The repository currently contains this project overview. Code, model checkpoints, and data are not included in this initial release.
